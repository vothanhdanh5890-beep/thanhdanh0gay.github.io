Tin học 12 – Bài 13: Khái niệm, vai trò của CSS

Phần 1: Luyện tập

Luyện tập 1 trang 75:

Câu hỏi: Khẳng định “Ngôn ngữ định dạng CSS chính là ngôn ngữ HTML” là đúng hay sai?

Lời giải: Sai. CSS không phải là HTML. HTML tạo cấu trúc trang web, còn CSS dùng để điều chỉnh cách hiển thị như màu sắc, font, khoảng cách,... CSS là ngôn ngữ độc lập để định dạng trang web.

Luyện tập 2 trang 75:

Câu hỏi: Khẳng định “Có thể chỉ cần thay đổi thông tin của tệp CSS sẽ làm thay đổi định dạng của nhiều trang web thậm chí của cả một trang website” là đúng hay sai?

Lời giải: Đúng. Khi chỉnh sửa tệp CSS chung, toàn bộ các trang sử dụng tệp đó sẽ thay đổi giao diện.

Phần 2: Vận dụng

Vận dụng 1 trang 75:

Câu hỏi: Trình bày sự giống nhau và tương thích của Style Sheet trong phần mềm soạn thảo văn bản với CSS.

Lời giải:

  • Cấu trúc & cú pháp: cả hai đều tuân theo cú pháp và quy tắc định dạng tương tự.
  • Tính tái sử dụng: có thể áp dụng lại cho nhiều đoạn văn hoặc nhiều trang web.
  • Khuôn mẫu định dạng: cho phép tạo template định dạng cho văn bản hoặc HTML.
  • Kiểm soát phong cách: kiểm soát màu sắc, font, kích thước, khoảng cách,...

Vận dụng 2 trang 75:

Dưới đây là trang web trình bày lịch sử CSS:

Lịch sử CSS

Ý tưởng CSS do kỹ sư Hakon Wium Lie đưa ra năm 1994 khi làm việc với Tim Berners-Lee tại CERN.

CSS giúp tách phần nội dung HTML và phần định dạng.

Lịch sử các phiên bản đầu tiên

CSS1 ra đời năm 1996.

CSS2 hoàn thiện năm 1998, bản CSS2.1 ra mắt 2011 và cập nhật 2016.

Các phiên bản tiếp theo

CSS3 phát triển theo từng module và vẫn đang mở rộng.

Các chuẩn CSS4 và CSS5 vẫn đang tiếp tục được phát triển.

W3C là tổ chức chịu trách nhiệm phát triển chuẩn CSS: www.w3.org
