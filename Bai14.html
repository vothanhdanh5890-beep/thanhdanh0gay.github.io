Yêu cầu: Liệt kê các thuộc tính CSS liên quan đến định dạng đoạn văn bản.

(Hình minh họa được đề cập trong SGK)

Các thuộc tính CSS thường dùng:

  • font-family
  • font-size
  • font-style
  • font-weight
  • color
  • text-align
  • text-indent
  • line-height
  • text-decoration

2. Vận dụng

Vận dụng 1 trang 82 Tin học 12

Lời giải:

  • font-variant: quy định kiểu chữ hoa (normal, small-caps).
  • letter-spacing: khoảng cách giữa các ký tự.
  • word-spacing: khoảng cách giữa các từ.
  • text-shadow: tạo hiệu ứng bóng cho chữ.

Vận dụng 2 trang 82 Tin học 12

Thiết lập hai tệp CSS khác nhau để định dạng bài "Lịch sử CSS".

Kiểu 1:

/* style1.css */
body {
    font-family: Arial, sans-serif;
    font-size: 16px;
    color: #333;
}

h1 {
    font-family: "Times New Roman", serif;
    font-size: 28px;
    color: #990000;
}

p {
    font-family: "Courier New", monospace;
    font-size: 14px;
    color: #666666;
}

Kiểu 2:

/* style2.css */
body {
    font-family: Verdana, Arial, sans-serif;
    font-size: 18px;
    color: #555555;
}

h1 {
    font-family: "Helvetica Neue", Arial, sans-serif;
    font-size: 32px;
    color: #006600;
}

p {
    font-family: Georgia, serif;
    font-size: 16px;
    color: #888888;
}
